# dashboard

E-ink dashboards for two Seeed reTerminal displays at home:

- E1001: 7.5", 800x480, 4-level gray
- E1003: 10.3", 1404x1872, 16-level gray

Content: car status, weather, calendar, power usage.

See [docs/research.md](docs/research.md) for firmware options, requirements and the chosen approach.
